# Compatibility

- Tested with Claude Code 2.1.302.
- The minimum Claude Code version for plugin dependencies and plugin skills is unconfirmed. The documentation consulted for this release does not state one.
- The course material this plugin was adapted from makes a claim of Claude Code 2.1.110 or later. That claim is unconfirmed and is not repeated here as a requirement.

Commands used in this plugin's documentation: `claude plugin install`, `claude plugin eval`, `claude plugin marketplace add`.
