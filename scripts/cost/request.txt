The greeting tool should accept an optional name and print "Hello, <name>!"; with no name it prints "Hello, world!". An empty name or a name made only of whitespace counts as no name. The 40-character limit counts Unicode code points. A name longer than 40 characters must be rejected: print "Error: name must be at most 40 characters." to stderr and exit with status 1. Nothing else is in scope; there are no further edge cases or open questions.
